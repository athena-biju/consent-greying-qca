## Research boundaries

This is a qualitative-methods archive, not an investment project. A coding frame documents the analytical categories applied; it does not alone establish intercoder reliability, representative sampling, or causal inference. Any underlying quotations or data should be used consistently with consent, platform terms and applicable research-ethics requirements.
